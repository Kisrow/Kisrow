## 🧑‍💻 Немного обо мне

Я **Frontend-разработчик**. Создаю интерфейсы, разбираюсь в сложных системах и периодически задаюсь вопросом:

> «А почему JavaScript вообще так работает?»

Мне интересно не просто писать код, а понимать, что происходит под капотом.

Иногда это приводит к интересным открытиям. Иногда — к многочасовому чтению спецификации ECMAScript.

### ⚡ Чем занимаюсь

- 🏗️ Работал с enterprise-приложениями, микрофронтендами и большими кодовыми базами.
- 🧠 Изучаю алгоритмы, структуры данных и внутреннее устройство JavaScript.
- 📦 Разрабатываю **Warely** — собственную систему управления складскими запасами.
- 🔬 Экспериментирую с Node.js, базами данных и архитектурой приложений.
- 🎮 Иногда закрываю VS Code и вспоминаю, что существуют видеоигры.
